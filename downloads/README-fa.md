# خروجی بهینه‌شدهٔ ایرانسل

این شاخه فایل‌های آمادهٔ دانلود را دارد؛ شاخهٔ master تغییر نکرده است.

- [خروجی صفحهٔ اصلی](Irancell-Home-Optimized.zip) — فایل شروع `Irancell-Home-v97.html`؛
- [خروجی فهرست شماره‌ها](Irancell-Simcards-Optimized.zip) — فایل شروع `simcards-direct.html`؛

دو بستهٔ اول صفحات مرتبط و پوشهٔ assets را نیز دارند تا مسیرهای حساب و خرید خراب نشوند. همهٔ ZIP را استخراج کنید و assets را کنار HTMLها نگه دارید. برای اجرای HTTP بررسی‌شده، از ریشهٔ بسته `python3 scripts/serve.py` را اجرا کنید. راهنمای هر بسته داخل آن است.

Lighthouse موبایل: صفحهٔ اصلی Performance برابر ۸۵ و فهرست شماره‌ها ۹۹؛ SEO هر دو صفحهٔ عمومی ۱۰۰. این نتایج آزمایشگاهی‌اند. دو زمینهٔ موجی تزئینی طبق اجازهٔ کاربر حذف شده‌اند و انتقال تصویر بنر حفظ شده است. ورود و پرداخت همان رفتار نمایشی اولیه را دارند. سایت روی دامنهٔ irancell.ir منتشر نشده است؛ این شاخه برای تحویل فایل‌هاست.

برای دریافت ZIP در GitHub از گزینهٔ دانلود فایل خام استفاده کنید. SHA256 فایل‌ها در [SHA256SUMS.txt](SHA256SUMS.txt) آمده است.
